Kortext design system

12 Eylül birleşmesinden sonraki sistem. Her şey panelin kendi CSS'iyle çizildi: ui/src/index.css olduğu gibi gömülü, sınıflar panelin sınıfları. dev/DESIGN.md argümanı, bu sayfa görünümü; bölüm numaraları belgenin.

0 · Principles

Quiet is correct. Bir düzine ajan paralel çalışsa da ekran sakin. Renk ancak söyleyecek bir şeyi olunca girer.
Colour carries meaning. Yeşil onay, kırmızı hata, pembe talep. Süs rengi yok.
Every token names a job, not a size. --fs-body nereye gittiğini söyler; --fs-13 sadece sayı.
Machine and human write differently. Yol, id, komut — mono. İnsanın okuduğu her cümle — sistemin kendi sans fontu.
One configuration. Tek eksen: tema.
Never: gradient, emoji, süs SVG, sol kenarı renkli yuvarlak kart, Inter/Roboto.

1 · Theme

Üç durum. Auto işletim sistemini izler, ilk açılış budur; Light ve Dark kullanıcının seçimi, localStorage'da tutulur. Yukarıdaki anahtar bu sayfayı değiştirir.

Tek kontrol — .kx-theme, başlıkta bir ikon; öznitelik yoksa auto
:root                    { /* light */ }
:root[data-theme='dark'] { /* dark */ }
@media (prefers-color-scheme: dark) {
  :root:not([data-theme='light']) { /* dark, ikinci kez */ }
}

8 · State vocabulary

Sistemin kalbi. Bir belge tam olarak bir durumda — nerede olduğu. Rozetler üstüne biner — ne borçlu olduğu. İki soru, iki gösterim.

State — .kx-status: 20px hap, nokta + kelime, durumun tonunda kenarlık
waitingqueued — or written and waiting for you, which the approve badge saysneutral
writingthe agent is writing it nowblue, the dot pulses
readinga recheck is running against it now — the agent reads, it does not writeblue, the dot pulses
pausedwriting was stoppedamber
approvedyou approved itgreen
failedthe last attempt fell over — asks for a Retryred
n/aconsidered, deliberately skippedno ground, faint outline
Badge — .kx-badge: yuvarlak hap, noktasız — ne borçlu, hangi tür bekleyiş
reviewAction Needed items stand on this document — questions, incoming or outgoing requests; the tooltip lists thempink · Action needed
approvenothing open — approve itviolet · Action needed
recheckan input moved; read again when it settles — the tooltip names the inputamber · To do while queued, Doing while reading
revisionthe run is a rewrite of what already stands, not a first draftmuted · Doing

Rozet yalnız durumun söylemediğini söylerken çizilir. queue ve draft veride var, ekranda yok: To do'da waiting zaten sırada demek, writing zaten ilk taslak — yalnız yeniden yazım bir kelime ister, o da revision.

A badge beats the state. failed durumu ya da review rozeti taşıyan her şey Action needed'a gider. Hareket eden girdi haber, iş değil — rozet olmaz; recheck tooltip'te söyler, drawer'daki band adını verir.

11 · Writing

Headings, code and names are always English. Başlıklar yapıdır; başka belgeler onları adıyla anar.
Prose follows the chosen document language. Seçim yoksa brief'in dili.
Product copy is in the interface language. Belgenin dilinden farklı olabilir.
A name is never translated. PRODUCT.md her dilde PRODUCT.md.

13 · Rules

Do
  • build from tokens
  • one primary button per screen
  • destructive action at the bottom, as a quiet link
  • state and debt shown separately
  • everything the machine owns in mono
  • auto as the initial theme; check light and dark on every change
Don't
  • invent a state colour — the set is closed
  • give a persona or category its own colour
  • half-pixel sizes
  • two button heights on one screen
  • a warning in colour alone
  • gradients, emoji, decorative SVG
